### 2.2 Extended Thinking（扩展思考）

```python
# 开启深度思考模式，处理复杂问题
response = client.messages.create(
    model="claude-opus-4-6",
    max_tokens=16000,
    thinking={
        "type": "enabled",
        "budget_tokens": 10000  # 给 Claude 更多"思考空间"
    },
    messages=[{
        "role": "user",
        "content": "设计一个可以处理百万级并发的分布式消息队列架构"
    }]
)

# 思考过程和最终回答分开
for block in response.content:
    if block.type == "thinking":
        print(f"思考过程: {block.thinking}")
    elif block.type == "text":
        print(f"最终回答: {block.text}")
```

**场景：** 数学证明、复杂架构设计、多步骤推理

### 2.3 Prompt Caching（提示词缓存）

**节省 90% 成本的关键技巧：**

```python
# 将长系统提示词缓存（一次支付，多次复用）
response = client.messages.create(

    system=[

            "type": "text",

            "cache_control": {"type": "ephemeral"}  # 缓存这部分
        }
    ],
    messages=[{"role": "user", "content": user_question}]

# 第二次调用：系统提示词从缓存读取，费用降低 90%
```

**何时使用：**
- 长文档问答（文档固定，问题变化）
- 知识库 QA
- 大型代码库分析

## 三、Manus AI 的设计理念（可借鉴）

Manus（2025年爆红的中国团队产品）的核心创新：

### 核心架构

```
用户意图
    ↓
规划 Agent（高层思考）
    ↓
任务分解（Planner）
    ↓
┌──────┬──────┬──────┐
│浏览器│代码  │文件  │ Worker Agents（并行）
│操作  │执行  │管理  │
└──────┴──────┴──────┘
    ↓
结果整合 + 向用户展示
```

**可借鉴的设计：**

1. **持久化沙箱**：每个任务在独立环境执行，状态持久
2. **工具即一等公民**：浏览器、代码执行、文件系统深度集成
3. **异步执行**：用户提交后可离开，Agent 后台完成
4. **可视化过程**：用户可以观看 Agent 的操作过程

## 四、知识盲区补全：你可能不知道的重要概念

### 4.1 Agentic Loop（智能体循环）

```
Observe → Think → Act → Observe → Think → Act → ...
(观察)   (思考)  (行动)
```

关键指标：
- **循环次数**：完成任务需要几次循环？越少越好
- **中止条件**：何时停止？需要显式设计
- **人工介入点**：哪些决策需要人来确认？

### 4.2 Tool Use vs Function Calling

```python
# Anthropic 叫 Tool Use
tools = [{
    "name": "get_weather",
    "description": "获取天气",
    "input_schema": {
        "type": "object",
        "properties": {
            "location": {"type": "string", "description": "城市名"}
        },
        "required": ["location"]
    }
}]

# OpenAI 叫 Function Calling
functions = [{
    "name": "get_weather",
    "description": "获取天气",
    "parameters": {
        "type": "object",
        "properties": {
            "location": {"type": "string"}
        }
    }
}]

# 本质一样，叫法不同
```

### 4.3 RAG 的进化：从基础到高级

```
RAG 进化路径：

Naive RAG          →   Advanced RAG       →   Agentic RAG
(朴素)                  (进阶)                  (智能体)

- 分块+检索+生成     - 查询改写            - 主动决定是否检索
- 固定 chunk size   - 混合检索            - 多步检索推理
- 简单向量搜索       - 重排序(Rerank)      - 自我纠错
                    - 父子分块            - 动态知识库更新
```

**2026 年最佳实践：**
```python
class AgenticRAG:
    def answer(self, question: str) -> str:
        # 1. 查询分析：这个问题需要检索吗？
        needs_retrieval = self.classify_need(question)
        if not needs_retrieval:
            return self.llm.generate(question)  # 直接回答

        # 2. 查询改写：让搜索更准确
        improved_query = self.rewrite_query(question)

        # 3. 多路检索
        results = {
            "semantic": self.vector_search(improved_query),
            "keyword": self.bm25_search(improved_query),
            "graph": self.graph_search(improved_query)
        }

        # 4. 重排序：用小模型过滤最相关的
        top_results = self.rerank(question, merge(results), top_k=5)

        # 5. 生成 + 验证
        answer = self.generate_with_citations(question, top_results)
        if not self.verify_answer(answer, top_results):
            return self.retry_with_more_context(question)

        return answer
```

### 4.4 Structured Generation（结构化生成）

确保 LLM 总是输出合法 JSON/代码：

```python
# 方法1：Instructor 库（最推荐）
import instructor
from pydantic import BaseModel

client = instructor.from_anthropic(anthropic.Anthropic())

class CodeReviewResult(BaseModel):
    has_bugs: bool
    severity: str  # "critical" | "high" | "medium" | "low" | "none"
    issues: list[str]
    suggestions: list[str]
    score: int  # 0-100

# 永远返回合法的 CodeReviewResult 对象
result: CodeReviewResult = client.messages.create(
    model="claude-haiku-4-5-20251001",
    response_model=CodeReviewResult,
    messages=[{"role": "user", "content": f"审查代码：{code}"}]
)
print(result.score)  # 直接访问属性，不用解析
```

### 4.5 Evals（评估）— 最被忽视的重要实践

**大多数人做 Agent 只关注"能不能运行"，但忽略了"运行得有多好"：**

```python
# 建立评估框架
class AgentEvaluator:
    def __init__(self, agent, test_cases: list[dict]):
        self.agent = agent
        self.test_cases = test_cases

    def evaluate(self) -> EvalReport:
        results = []
        for case in self.test_cases:
            response = self.agent.run(case["input"])
            scores = {
                "correctness": self.score_correctness(response, case["expected"]),
                "completeness": self.score_completeness(response, case["criteria"]),
                "safety": self.score_safety(response),
                "efficiency": case["max_tokens"] / len(response)
            }
            results.append(scores)

        return EvalReport(results)

# 评估数据集示例
test_cases = [
    {
        "input": "Python 中如何避免 SQL 注入？",
        "expected_contains": ["参数化查询", "ORM", "prepared statement"],
        "expected_not_contains": ["字符串拼接", "format"],
        "criteria": ["给出代码示例", "解释原理"],
        "max_tokens": 500
    },

]
```

## 六、CLAUDE.md — Claude Code 的超级武器

这是很多人不知道的重要功能：

在项目根目录创建 `CLAUDE.md`，Claude Code 每次启动都会读取：

```markdown
# 项目规范

## 技术栈
- 语言：Python 3.11+
- 框架：FastAPI + SQLAlchemy
- 数据库：PostgreSQL
- 测试：pytest

## 编码规范
- 所有函数必须有类型注解
- 使用 async/await，避免同步 IO
- 错误处理用自定义异常类
- SQL 查询必须使用 ORM，禁止字符串拼接

## 项目结构
- src/api/: API 路由
- src/services/: 业务逻辑
- src/models/: 数据库模型
- tests/: 测试文件

## 常见操作
- 运行测试：pytest tests/ -v
- 启动服务：uvicorn src.main:app --reload
- 数据库迁移：alembic upgrade head

## 重要约束
- 不要修改 src/core/ 目录（核心库，只读）
- API 变更必须同步更新 OpenAPI 文档
- 所有外部调用都要有超时设置

## 当前工作状态
- 正在实现：用户认证模块
- 下一步：支付集成
- 已知问题：登录接口偶发 500 错误（待查）
```

**效果：** Claude Code 立刻变成了解你项目的专业队友，不用每次重复解释背景。
